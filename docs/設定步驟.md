# 設定步驟（約 10 分鐘，只需做一次）

網頁放在 GitHub Pages，「誰外出了」這份資料存在一份 Google 試算表。

## 一、建立資料來源（Google 試算表）

1. 打開 Google 試算表，建立一份新的空白試算表，檔名例如「行蹤告知表資料」。
2. 上方選單點「擴充功能」→「Apps Script」。
3. 把編輯器裡原有的內容全部刪掉，貼上本倉庫 `apps-script/Code.gs` 的全部內容，按存檔（磁碟片圖示）。
4. 上方函式下拉選單選 **setup**，按「執行」。第一次會要求授權：選你的帳號 →「進階」→「前往…（不安全）」→「允許」。（這是你自己寫的程式，只會讀寫這份試算表。）
5. 回到試算表，應該多了「人員、選項、行蹤」三個工作表。
6. 回到 Apps Script，右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製出現的「網頁應用程式網址」（結尾是 `/exec`）。

## 二、把網址交給網頁

1. 在 GitHub 倉庫點開 `config.js`，按鉛筆圖示編輯。
2. 把網址貼進 `window.APPS_SCRIPT_URL = "";` 的引號中，按「Commit changes」。

## 三、開啟 GitHub Pages

1. 倉庫 →「Settings」→ 左側「Pages」。
2. Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 約 1 分鐘後，頁面上方會顯示網址：`https://evanchi1111-sys.github.io/staff-whereabouts/`
   - 私有倉庫要使用 Pages，需要付費版 GitHub；若無法開啟，請把倉庫改為 Public（程式內沒有任何機密，資料在你的試算表裡）。

## 四、放進 SharePoint

在 SharePoint 頁面加入「快速連結」或「按鈕」，網址填上面的 GitHub Pages 網址即可。

## 之後要修改

- 同事名單、事由、地點：網頁最下方「名單設定」。
- 若改了 `Code.gs`：Apps Script →「部署」→「管理部署作業」→ 鉛筆 → 版本選「新版本」→ 部署（網址不變）。

## 注意

- 知道網址的人都能使用，沒有密碼。
- 網址（試算表後端）如果外流，別人也能寫入資料；請只把網頁連結放在內部。
