# 辦公室人員行蹤告知表

同事外出處理公務時，自己點名牌選「事由」與「地點」登記外出，回來按「我已回來」，辦公室其他同事開網頁就能看到誰在外面。

- 單一頁面、按鈕式操作，不需登入或密碼
- 週一至週五 07:30–16:30 顯示上班中／外出中；其餘時間與週末顯示「下班」
- 沒按「我已回來」的外出，到 16:30 自動結束
- 每 15 秒自動更新；不留歷史（結束超過一天的紀錄自動清除）
- 同事名單、事由、地點可在頁面最下方「名單設定」維護

## 架構

| 部分 | 內容 |
|---|---|
| 網頁 | `index.html`、`style.css`、`app.js`、`config.js`（純靜態，免建置，放在 GitHub Pages） |
| 資料 | Google 試算表 + Google Apps Script（`apps-script/Code.gs`） |

## 如何啟用

請看 [docs/設定步驟.md](docs/設定步驟.md)。

## 備註

- 國定假日不會自動判斷，那幾天平日仍顯示「上班中」。
- 上下班判斷依使用者瀏覽器的本機時間（台灣）。
